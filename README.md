# Travel Map (prototype)

A fog-of-war travel log. The map stays covered until you've been there.

- **Explore**: reveals the map as you walk or drive, logs suburbs and towns with visit tiers (Passed by, Dropped by, Stayed, Travelled, Lived)
- **Live guide**: chime and spoken intro when you enter a new area, plus landmarks you pass ("On your left…")
- **Photo**: pin a bird, animal or sight to the map
- **Demo drive**: Settings → Demo drive through Sydney

All data stays on the phone (IndexedDB). Back up from Settings.

Data: map tiles © OpenStreetMap contributors · place names via Nominatim · stories from Wikipedia (CC BY-SA).

Prototype limits: as a web app it only tracks while open on screen.
